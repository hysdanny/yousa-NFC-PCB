# 嘉立创 PCB 下单教程

适用工程：本仓库 2026-10-26 版。重点是 **PCB1沉金** 和 **PCB2丝印（彩色丝印）**。

## 先选对 PCB 文档

1. 下载 `hardware/` 中的完整 `.epro2` 文件，在嘉立创 EDA **专业版**导入工程。工程记录的编辑器版本为 4.1.78，建议使用兼容该工程格式的专业版。
2. 展开工程的 PCB 文档，打开 **PCB1沉金** 或 **PCB2丝印**。两块板分别导出、分别下单，便于核对图案与工艺。
3. 在 2D/3D 预览中检查正反面、人物方向、板框、挂孔、天线线圈和 NFC 焊盘。底层在编辑视图中可能呈镜像，应结合底面预览判断，勿仅凭编辑图手动镜像。
4. PCB2 使用彩色丝印效果预览，重点看整张插画是否显示、板边是否留白，以及焊盘是否被图片覆盖。

## 两款下单参数对照

| 下单项目 | PCB1沉金 | PCB2丝印（彩色丝印） |
| --- | --- | --- |
| 材料 | FR-4 | FR-4 |
| 铜层数量 | 2 层，以文件解析复核 | 2 层，以文件解析复核 |
| **成品板厚** | **1.2 mm** | **1.2 mm** |
| **阻焊颜色** | **白色** | **白色** |
| **焊盘喷镀 / 表面处理** | **沉金** | **沉金** |
| **字符工艺** | 普通字符工艺，按工程需要保留 | **嘉立创 EDA 彩色丝印** |
| 彩色制造文件 | 金色主体不依赖彩色制造文件 | **导出时勾选彩色丝印，并保留专用文件** |
| 彩印面 | 按原工程字符层 | 本工程全彩图片对象位于顶层丝印，核对顶面彩印及背面效果 |
| 板面标志 | 建议选择不加标志，保护展示效果 | 按官方要求选择**板面不加任何标志** |
| 数量 | 按需 | 按需 |
| 尺寸 | 以 PCB1沉金 板框及工厂解析为准 | 以 PCB2丝印 板框及工厂解析为准 |
| 其他参数 | 根据原设计和工厂能力选择，避免更改天线及开窗 | 同左，另外核对彩印数据与板框的对齐 |

PCB1 的金色图案依赖铜层、阻焊开窗与沉金。下单选沉金也不会将任意普通字符自动变成金属图案。PCB2 的彩色插画依赖彩色丝印数据；表面处理仍选沉金。官方目前要求的彩色丝印组合为 FR-4、白色阻焊、沉金，再选择嘉立创 EDA 彩色丝印。[来源：官方彩色丝印教程](https://prodocs.lceda.cn/cn/pcb/other-draw-colorful-silkscreen/)

## 方式一：从专业版一键下单

1. 确认当前激活的是需要生产的 PCB 文档。
2. PCB2 先在「设置 → PCB → 通用」开启「使用嘉立创彩色丝印工艺」，并检查预览效果。
3. 使用「下单 → PCB 下单」，进入嘉立创订单页面。
4. 逐项核对上表，尤其是 **1.2 mm、白色阻焊、沉金**。PCB2 还要选择 **嘉立创 EDA 彩色丝印**。如果没有彩色选项，先复查材料、层数、白色阻焊和沉金的组合是否正确。
5. 检查文件解析预览和实际板框，确认没有上传成另一块板。PCB2 的彩色效果需单独确认，普通铜层 Gerber 预览不能代替彩印生产稿。
6. 提交工厂审核，查看生产稿及最终报价。确认图案、开窗、彩印与板框对齐后再付款。

菜单位置可能随版本调整。[官方快速入门与下单入口](https://prodocs.lceda.cn/cn/quick-start.html)

## 方式二：导出 Gerber 后上传

1. 打开目标 PCB，选择「导出 → PCB 制板文件（Gerber）」。
2. PCB1 保留铜层、阻焊、字符、板框与钻孔等必要生产层。
3. **PCB2 勾选「导出彩色丝印」**。导出的 ZIP 除常规 Gerber 外，还应带有所用面的彩色丝印专用数据。官方列出的文件名包括顶层 `Fabrication_ColorfulTopSilkscreen.FCTS`、底层 `Fabrication_ColorfulBottomSilkscreen.FCBS` 及彩色板框/定位相关文件，实际以版本和所用面为准。
4. 将导出的**完整 ZIP** 上传到[嘉立创](https://www.jlc.com/)的 PCB 下单入口。不要只上传 PNG/PPT，也不要手动删掉彩色制造文件。
5. 按上表设定参数，完成审核及生产稿确认。

[来源：官方 Gerber 导出说明](https://prodocs.lceda.cn/cn/pcb/export-pcb-fabrication-file-gerber/)

## 可复制的订单备注

PCB1沉金：

> 泠鸢 yousa NFC 纪念卡，PCB1沉金版本。成品板厚 1.2 mm，白色阻焊，沉金。图案由铜层及阻焊开窗形成，请按源文件保留图案、天线、NFC 焊盘和挂孔。板面不加额外标志，请提供生产稿确认；如需改动图案或天线，请先联系确认。

PCB2彩色丝印：

> 泠鸢 yousa NFC 纪念卡，PCB2丝印版本。成品板厚 1.2 mm，白色阻焊，沉金，使用嘉立创 EDA 彩色丝印数据。请确认顶面全彩插画完整打印，板面不加任何标志；重点核对图片与板框对齐、边缘留白及 NFC 焊盘区域。请提供彩色效果及生产稿确认，如需调整板框、位置或天线，请先联系确认。

备注用于辅助沟通，不能代替下单页面参数或缺失的彩色制造文件。

## 付款前检查

- 当前 PCB 名称及上传文件一致。
- 板厚为 **1.2 mm**，阻焊为 **白色**，表面处理为 **沉金**。
- PCB2 的字符工艺明确选中**嘉立创 EDA 彩色丝印**，且生产资料包含全彩图片。
- 两款板均核对了天线、NFC 焊盘、挂孔、板框及正反面方向。
- PCB2 已检查原工程提示的边缘微小留白。
- 确认板面标志处理，以及工厂对沉金图案、图案细节和彩印的加工结果。
- 报价、数量、收货信息和交期无误，再付款。
